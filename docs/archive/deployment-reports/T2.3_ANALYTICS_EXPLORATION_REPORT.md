**Project:** MA Deal Room WordPress Plugin
**Task:** Explore current analytics and reporting capabilities to plan T2.3

## Executive Summary

The MA Deal Room plugin has **foundational analytics infrastructure in place** but **lacks comprehensive reporting and advanced analytics features**. The plugin currently provides:

- **Basic dashboard metrics** with transaction counts, status breakdowns, and task completion rates
- **Template analytics** with usage tracking and performance metrics by phase
- **Event logging system** for audit trails
- **Simple export capability** for task definitions (CSV/JSON)
- **UI framework** for report generation (skeleton in place)

### Key Gaps for T2.3:
1. No PDF export functionality
2. No transaction-level analytics API endpoints
3. No vendor request analytics/tracking
4. No date range filtering on analytics endpoints
5. No bulk data export (Excel/CSV for transactions)
6. No performance dashboards with historical trends
7. No custom report builder backend

```typescript
// Average days to close (DashboardMetrics.tsx:107-115)
const avgDaysToClose = closedTransactions.length > 0
  ? Math.round(
      closedTransactions.reduce((sum, t) => {
        const created = new Date(t.created_at);
        const closed = new Date(t.actual_closing_date!);
        return sum + differenceInDays(closed, created);
      }, 0) / closedTransactions.length
    )
  : 0;
```

## 6. GAPS ANALYSIS FOR T2.3

### Critical Gaps

#### 1. **No PDF Export Backend**
- ReportGenerator UI exists but no PHP implementation
- No library integration (mPDF, TCPDF, or similar)
- No template system for report layouts

#### 2. **No Transaction-Level Analytics API**
- Dashboard calculates metrics client-side from basic transaction list
- No dedicated analytics endpoint with date range filtering
- No pre-calculated metrics in backend
- Missing endpoints:
  - `GET /transactions/analytics` - summary stats by date
  - `GET /transactions/analytics/by-status` - breakdown by status
  - `GET /transactions/analytics/agent-performance` - agent KPIs
  - `GET /transactions/analytics/timeline` - historical trends

#### 3. **No Excel/XLSX Export**
- Only CSV and JSON available for task definitions
- No structured Excel workbooks with multiple sheets
- No Excel formatting (colors, headers, merged cells)

#### 4. **No Vendor Request Analytics**
- Vendor requests tracked in DB but no analytics endpoints
- No metrics on:
  - Completion rates by vendor type
  - Average turnaround time
  - Status distribution
  - Document submission rates

#### 5. **No Date Range Filtering on APIs**
- Transaction list doesn't support date filtering via API
- Client-side filtering from full data set (not scalable)
- Need backend date range parameters

#### 6. **No Bulk Export Functionality**
- Can't export all transactions with all their data
- Missing CSV export for transactions/tasks/documents

#### 7. **No Performance/Trend Analytics**
- Dashboard shows current metrics only
- No historical data for trend analysis

- No conversion funnel tracking

#### 8. **No Custom Report Builder Backend**
- ReportGenerator UI ready but no backend queries
- No filter/grouping engine
- No saved report definitions

#### 9. **No Agent/Team Performance Metrics**
- assigned_agent_id exists but no performance tracking
- Missing KPI calculations per agent
- No team-level analytics

#### 10. **No Document Analytics**
- Documents are tracked but no analytics
- Missing metrics:
