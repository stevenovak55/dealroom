**Database:**
- Migration 026_create_docusign_webhook_log_table.sql
- Comprehensive webhook logging with processing status

**Workflow:**
1. DocuSign sends webhook → POST /docusign/webhook
2. Extract HMAC signature from X-DocuSign-Signature-1 header
3. Verify signature with WebhookHandler
4. Parse event data (envelope_id, event_type)
5. Log webhook to database
6. Update envelope status
7. Download documents if completed (combined PDF + certificate)
8. Return 200 OK to DocuSign

## Usage Examples

### Configure DocuSign
1. Navigate to **Integrations > DocuSign** in admin menu
2. Enter Integration Key, User ID, Account ID
3. Paste RSA private key (PEM format)
4. Select environment (sandbox/production)
5. Click **Save Configuration**
6. Click **Test Connection** to validate

### Send Document for Signature
```php
// Create envelope from template
$envelope = $envelope_service->createEnvelopeFromTemplate([
    'template_id' => 'template-guid',
    'recipients' => [
        [
            'email' => 'buyer@example.com',
            'name' => 'John Buyer',
            'role' => 'signer',
            'routing_order' => 1,
        ],
        [
            'email' => 'seller@example.com',
            'name' => 'Jane Seller',
            'role' => 'signer',
            'routing_order' => 2,
        ],
    ],
    'subject' => 'Purchase Agreement',
    'message' => 'Please review and sign the purchase agreement',
], $transaction_id);

// Send envelope
$client->sendEnvelope($envelope['envelope_id']);
```

### Display Status in React
```tsx
import { EnvelopeStatus } from '@/components/DocuSign';

function TransactionDetail({ transaction }) {

            DocuSign Status
          </Typography>
          <EnvelopeStatus 
            envelopeId={transaction.docusign_envelope_id}

        </Box>
      )}
    </Box>
  );
}
```

## Security Features

1. **OAuth 2.0 JWT Authentication**
   - Server-to-server authentication
   - No user intervention required
   - Private key stored encrypted in database

2. **HMAC Signature Verification**
   - All webhooks validated with SHA256 HMAC
   - Constant-time comparison prevents timing attacks
   - Configurable webhook secret via WordPress filter

3. **Encrypted Credential Storage**
   - Private keys encrypted using defuse/php-encryption
   - Integration keys and user IDs encrypted
   - Secure storage in WordPress database

4. **Document Security**
   - Documents stored in protected directories
   - .htaccess prevents direct access
   - WordPress attachment permissions enforced
