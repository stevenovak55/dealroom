## Technical Details

### WordPress Media Upload Integration

The implementation uses WordPress's built-in REST API for media uploads:

```typescript
// Endpoint: POST /wp-json/wp/v2/media
// Returns: { source_url: "https://..." }
```

**Upload Flow:**
1. User selects/drops file
2. Client validates file type and size
3. Upload to WordPress media library via XHR
4. Progress tracking (0-100%)
5. WordPress returns `source_url`
6. Update vendor request with document URL
7. Refresh vendor data
8. Display success notification

### File Validation

**Accepted Types:**
- PDF: `application/pdf`
- PNG: `image/png`
- JPG/JPEG: `image/jpeg`, `image/jpg`

**Size Limit:**
- Maximum: 10MB (10,485,760 bytes)
- Configurable via component props

## Integration Points

### Backend API

**Vendor Request Update:**
```typescript
POST /wp-json/ma-deal-room/v1/vendor/{token}
{
  "document_url": "https://example.com/wp-content/uploads/2025/11/document.pdf"
}
```

**Expected Response:**
```typescript
{
  "success": true,
  "data": {
    "id": 1,
    "document_url": "https://...",
    // ... other vendor request fields
  }
}
```

### WordPress Media Library

**Upload Endpoint:**
```typescript
POST /wp-json/wp/v2/media
Content-Type: multipart/form-data

file: [binary data]
```

**Success Response (201):**
```json
{
  "id": 123,
  "source_url": "https://example.com/wp-content/uploads/2025/11/file.pdf",
  "mime_type": "application/pdf",
  "title": {
    "rendered": "file"
  }
}
```
