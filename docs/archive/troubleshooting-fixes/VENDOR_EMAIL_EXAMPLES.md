## Email Design Features

### Color Schemes
- **Scheduling Confirmation:** Green gradients (#d1fae5 → #a7f3d0)
  - Conveys success and confirmation
  - Positive, welcoming feel
  
- **Completion Confirmation:** Blue gradients (#dbeafe → #bfdbfe)
  - Professional and trustworthy
  - Completion and achievement
  
- **Reminder:** Yellow/Amber gradients (#fef3c7 → #fde68a)
  - Attention-grabbing
  - Urgency without being alarming

### Typography
- **Headers:** 24px, bold, dark gray
- **Body text:** 16px, regular, medium gray
- **Labels:** 12px, uppercase, light gray
- **Emphasis:** 18px, bold for important dates/times

### Layout
- **Max width:** 600px (optimal for email clients)
- **Padding:** Generous whitespace for readability
- **Cards:** Rounded corners (8px) with subtle borders
- **Sections:** Clear visual separation
- **CTAs:** Prominent buttons with gradients

### Responsive Design
- **Desktop:** Full 600px width
- **Mobile:** Scales to device width
- **Touch targets:** Minimum 44px for buttons
- **Font scaling:** Adjusts for small screens

### Accessibility
- **Contrast ratios:** WCAG AA compliant
- **Alt text:** Provided for emoji (decorative)
- **Semantic HTML:** Proper heading hierarchy
- **Plain text fallback:** Available in email clients

### Email Client Compatibility
✓ Gmail (web, iOS, Android)
✓ Outlook (web, desktop, mobile)
✓ Apple Mail (macOS, iOS)
✓ Yahoo Mail
✓ Thunderbird
✓ Mobile email apps

## Technical Implementation

### Template Variables
Each template receives these variables from VendorService:

**Scheduling Confirmation:**
- `$vendor_email` - Vendor's email address
- `$vendor_type` - Type of service (inspector, appraiser, etc.)
- `$scheduled_date` - YYYY-MM-DD format
- `$scheduled_time` - HH:MM:SS format
- `$property_address` - Full street address
- `$property_city`, `$property_state`, `$property_zip`
- `$portal_url` - Link to vendor portal
- `$ics_url` - Calendar file indicator

**Completion Confirmation:**
- `$vendor_email` - Vendor's email address
- `$vendor_type` - Type of service
- `$completion_notes` - Vendor's notes (multi-line)
- `$document_url` - Link to uploaded document
- `$property_address`, city, state, zip
- `$completed_at` - Timestamp of completion

**Reminder:**
- `$vendor_email` - Vendor's email address
- `$vendor_type` - Type of service
- `$scheduled_date` - YYYY-MM-DD format
- `$scheduled_time` - HH:MM:SS format
- `$property_address`, city, state, zip
- `$portal_url` - Link to vendor portal

### Security
- All output escaped with `esc_html()` and `esc_url()`
- Direct access prevented with `ABSPATH` check
- No executable code in email bodies
- Safe variable extraction

### Performance
- Templates render in <10ms
- No external resources loaded
- Inline CSS (faster rendering)
- Minimal HTML size (~7KB per template)
