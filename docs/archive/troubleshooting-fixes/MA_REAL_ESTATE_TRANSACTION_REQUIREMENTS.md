## Transaction Type Taxonomy

Massachusetts real estate transactions should be categorized into the following distinct types:

### 1. **Buy Side - Purchase Transaction**
- **Description:** Agent represents the buyer in a purchase transaction
- **Key Characteristic:** Buyer representation with fiduciary duty to buyer
- **Required Disclosure:** MA Mandatory Real Estate Licensee-Consumer Relationship Disclosure at first meeting
- **Unique Documents:**
  - Buyer Agency Agreement (mandatory as of 2025 NAR settlement)
  - Buyer fee disclosure and negotiation
  - Buyer's Offer to Purchase
  - Purchase & Sale Agreement (buyer execution)

### 2. **Sell Side - Listing Transaction**
- **Description:** Agent represents the seller in listing and sale of property
- **Key Characteristic:** Seller representation with fiduciary duty to seller
- **Required Disclosure:** MA Mandatory Real Estate Licensee-Consumer Relationship Disclosure at first meeting
- **Unique Documents:**
  - Listing Agreement (Exclusive Right to Sell, Exclusive Agency, or Open Listing)
  - Seller's Property Disclosure Statement
  - MLS Listing submission
  - Lead paint disclosure (if pre-1978)

### 3. **Rental - Landlord Representation**
- **Description:** Agent represents property owner in leasing property to tenants
- **Key Characteristic:** Landlord representation for rental property
- **Required Disclosure:** Written fee disclosure at first personal meeting (required by MA law)
- **Unique Documents:**
  - Rental Listing Agreement
  - Lease Agreement preparation
  - Security Deposit receipt and banking (must be in MA bank, interest-bearing)
  - Statement of Condition (within 10 days of lease or deposit receipt)
  - Fire insurance disclosure (within 15 days of lease)
  - Lead paint disclosure (if pre-1978)

### 4. **Rental - Tenant Representation**
- **Description:** Agent represents prospective tenant in finding rental property
- **Key Characteristic:** Tenant representation
- **Required Disclosure:** Written fee disclosure at first personal meeting (M.G.L. c. 112, § 87 DDD ½)
- **Licensing Requirement:** Must be licensed broker or salesperson
- **Unique Documents:**
  - Tenant representation agreement
  - Rental application assistance
  - Lease review and negotiation
  - Lead paint notification receipt

### 5. **Commercial Purchase - Buy Side**
- **Description:** Agent represents buyer in commercial property purchase
- **Key Characteristic:** Commercial property (not residential)
- **Higher Complexity:** Environmental reviews, zoning, commercial financing
- **Unique Documents:**
  - Letter of Intent (LOI)
  - Commercial Purchase & Sale Agreement
  - Environmental Phase I/II assessments
  - Zoning compliance verification
  - Commercial lease reviews (if tenant-occupied)

### 6. **Commercial Listing - Sell Side**
- **Description:** Agent represents seller in commercial property sale
- **Key Characteristic:** Commercial property listing
- **Unique Documents:**
  - Commercial listing agreement
  - Rent rolls and lease schedules
  - Operating statements and financial disclosures
  - Environmental disclosures

## Property Type Taxonomy

### Residential Property Types

#### 1. **Single-Family Home (SFH)**
- **Subcategories:**
  - SFH with City Water/Sewer
  - SFH with Septic System
  - SFH with Private Well
  - SFH with Septic + Well (most complex)

#### 2. **Condominium**
- **Governed by:** M.G.L. Chapter 183A (Massachusetts Condominium Act)
- **Special Requirements:**
  - HOA/Condo Association documents
  - 6(d) Certificate (M.G.L. c. 183A, § 6(d))
  - Master Deed, Bylaws, Budget, Meeting Minutes
  - Condo questionnaire for lenders

#### 3. **Multifamily (2+ Units)**
- **Special Considerations:**
  - Tenant-occupied units
  - Lease transfers
  - Security deposit transfers
  - Rent rolls
  - Tenant notifications
  - Investor analysis (income/expenses)

#### 4. **Land (Vacant/Development)**
- **Special Considerations:**
  - Zoning and permitted uses
  - Soil testing (perc tests for septic)
  - Survey requirements
  - Development potential analysis
  - Environmental assessments

#### 5. **Commercial**
- **Types:** Office, Retail, Industrial, Mixed-use
- **Special Considerations:**
  - Commercial zoning compliance
  - ADA compliance
  - Environmental Phase I/II
  - Tenant lease assignments
  - Operating expenses and CAM charges

## Universal Tasks (All Transactions)

These tasks apply to **ALL transaction types** regardless of whether buy-side, sell-side, rental, or commercial:

### Deal Setup & Initiation
1. **Create transaction record** - Set up transaction in system
2. **Collect basic property information** - Address, property type, key details
3. **Verify property ownership** - Public records check
4. **Present MA Agency Disclosure Form** - Required at first personal meeting (mandatory)
5. **Execute representation agreement** - Buyer agency, listing agreement, rental agreement, etc.
6. **Determine transaction timeline** - Key dates and milestones

### Party Onboarding
7. **Add client information to transaction** - Primary client details
8. **Add co-op agent (if applicable)** - Cooperating broker information
9. **Send welcome packet to client** - Introduction materials
10. **Obtain client contact preferences** - Communication preferences

### Communication & Coordination
11. **Schedule initial consultation** - Set up first detailed meeting
12. **Provide transaction timeline to client** - Share expected schedule
13. **Send regular status updates** - Weekly/bi-weekly updates
14. **Coordinate with transaction parties** - Attorneys, lenders, vendors

### Financial Tracking
15. **Create transaction financial ledger** - Track all money movements
16. **Monitor deposit/payment deadlines** - Track financial obligations
17. **Verify funds availability** - Confirm buyer/tenant financial capacity

### Legal & Compliance
18. **Lead paint disclosure (if pre-1978 property)** - Federal and MA requirement
19. **Review property disclosure requirements** - State-mandated disclosures
20. **Coordinate with attorneys** - Attorney review and preparation
21. **Maintain transaction documentation** - File all documents properly

### Closing Preparation
22. **Order title search** - Title examination
23. **Review title report** - Address any title issues
24. **Coordinate title insurance** - Arrange for title insurance
25. **Schedule final walkthrough** - Pre-closing inspection
26. **Prepare closing checklist** - Final items before closing

### Closing Day
27. **Verify all parties ready for closing** - Confirm attendance
28. **Verify wire transfer information** - Prevent wire fraud
29. **Attend closing** - Agent presence at closing
30. **Collect executed documents** - Get copies of signed docs

### Post-Closing
31. **Verify deed recording** - Confirm property transfer recorded
32. **Update MLS status (if applicable)** - Mark as sold/rented
33. **Distribute final settlement statements** - Provide to all parties
34. **Request client testimonial/review** - Ask for feedback
35. **Process commission payment** - Receive and track commission
36. **Close transaction in system** - Archive and complete record

## Transaction-Type Specific Tasks

### Buy Side - Purchase Transaction (ONLY)

#### Agency & Agreements
- **Sign Buyer Agency Agreement** - Mandatory representation agreement with fee negotiation
- **Execute Buyer Fee Agreement** - Disclose and agree on buyer's agent compensation
- **Review buyer's agent fiduciary duties** - Explain loyalty, care, disclosure, confidentiality

#### Financial Preparation
- **Obtain mortgage pre-approval letter** - Before making offers
- **Review buyer's financial capacity** - DTI, credit, down payment
- **Coordinate with buyer's lender** - Throughout financing process
- **Submit loan application** - After P&S execution
- **Track mortgage commitment deadline** - Usually 21-30 days from P&S
- **Obtain clear to close from lender** - Final loan approval

#### Offer & Negotiation
- **Prepare Offer to Purchase** - Buyer's initial offer document
- **Present offer to seller's agent** - Submit and communicate offer
- **Negotiate offer terms** - Price, contingencies, timeline
- **Collect initial deposit (earnest money)** - Typically $1,000 with offer
- **Deliver deposit to escrow holder** - Usually seller's attorney or listing agent

#### Purchase & Sale Agreement
- **Review P&S agreement draft** - Attorney-prepared document
- **Negotiate P&S terms with buyer** - Review and approve terms
- **Execute P&S agreement (buyer)** - Buyer signature
- **Collect additional deposit** - Typically 5% of purchase price at P&S
- **Deliver P&S deposit to escrow** - To designated escrow holder

#### Due Diligence & Inspection
- **Schedule home inspection** - General home inspection
- **Attend home inspection with buyer** - Be present for inspection
- **Review home inspection report with buyer** - Explain findings
- **Prepare inspection response** - Repair requests, credits, or waiver
- **Negotiate inspection items** - Work with seller on repairs/credits
- **Schedule specialized inspections** - Radon, mold, structural, etc.
- **Coordinate 10-day lead paint inspection period** - If buyer exercises right

#### Appraisal
- **Coordinate appraisal scheduling** - Lender-ordered appraisal
- **Provide access for appraiser** - Ensure property access
- **Review appraisal report** - Check for value issues
- **Address low appraisal (if applicable)** - Renegotiate or make up difference

#### Insurance
- **Obtain homeowners insurance quotes** - Required for closing
- **Verify insurance coverage in place** - Confirm before closing
- **Provide proof of insurance to lender** - Required for closing

#### Pre-Closing
- **Review HUD-1/Closing Disclosure** - Verify all costs accurate
- **Coordinate final walkthrough** - Day before or morning of closing
- **Verify property condition at walkthrough** - Ensure agreed-upon condition
- **Confirm closing time and location** - With attorney's office
- **Prepare closing funds wire** - Same-day wiring of down payment + closing costs
- **Verify seller has vacated** - Ensure property is empty

#### Closing
- **Review and explain closing documents to buyer** - ALTA statement, deed, note, mortgage
- **Verify buyer brings required ID** - Government-issued photo ID
- **Coordinate key transfer** - Obtain keys, garage openers, access codes

#### Post-Closing (Buyer-Specific)
- **Assist with utility transfers to buyer** - Electric, gas, water, internet
- **Provide buyer with vendor referrals** - Contractors, handyman, etc.
- **Schedule post-closing check-in** - 30-day follow-up

### Sell Side - Listing Transaction (ONLY)

#### Listing Setup
- **Execute Exclusive Right to Sell Agreement** - Most common listing type
- **Execute Exclusive Agency Agreement** - Or Open Listing (less common)
- **Determine listing price** - CMA and pricing strategy
- **Complete Comparative Market Analysis (CMA)** - Provide to seller
- **Establish listing commission structure** - Agree on commission split
- **Review seller's net proceeds estimate** - Calculate expected net

#### Property Preparation
- **Conduct pre-listing property assessment** - Walkthrough and notes
- **Recommend repairs/improvements** - Prepare property for market
- **Verify seller has made agreed repairs** - Confirm completion
- **Schedule professional photography** - High-quality listing photos
- **Coordinate virtual tour/video** - Optional but recommended
- **Arrange staging consultation** - Professional staging if needed
- **Install lockbox** - For agent showings
- **Install yard sign** - For Sale signage

#### Disclosure & Documentation
- **Complete Seller's Property Disclosure Statement** - Mandatory disclosure
- **Gather property documentation** - Deed, survey, permits, warranties
- **Collect utility bills** - For buyer information
- **Obtain septic pumping records** - If applicable
- **Collect HOA/Condo documents** - If applicable

#### Marketing & Showings
- **Enter listing into MLS** - Multiple Listing Service submission
- **Create property marketing materials** - Brochures, flyers, online listings
- **Distribute listing to agent network** - Email blast to cooperating agents
- **Schedule and host open houses** - Public showings
- **Coordinate private showings** - Agent showings
- **Provide showing feedback to seller** - Communicate buyer agent feedback
- **Adjust marketing strategy as needed** - Based on market response

#### Offers & Negotiation
- **Receive and review offers** - Analyze all offer terms
- **Present offers to seller** - Explain and recommend
- **Counter-offer preparation** - Draft seller's counter-offer
- **Negotiate on behalf of seller** - Price, terms, contingencies
- **Accept offer** - Execute accepted offer

#### Under Agreement
- **Respond to buyer's inspection requests** - Negotiate repairs or credits
- **Coordinate repair completion** - If seller agrees to repairs
- **Provide receipts for completed work** - Document repairs
- **Respond to buyer's attorney questions** - Title, survey, other issues

#### Appraisal Coordination
- **Prepare property for appraiser** - Ensure access and presentation
- **Provide comparable sales to appraiser** - Support listing price
- **Address appraisal challenges** - If value comes in low

#### Pre-Closing (Seller-Specific)
- **Coordinate seller's moving timeline** - Ensure timely vacancy
- **Verify seller has removed personal property** - As per agreement
- **Arrange for property to be cleaned** - Final cleaning before closing
- **Verify utilities remain on through closing** - For walkthrough
- **Prepare for possession transfer** - Keys, garage openers, mailbox key, etc.
- **Collect all keys and access devices** - For transfer to buyer

#### Closing (Seller-Specific)
- **Review seller's closing statement** - Verify all debits/credits
- **Coordinate seller's attendance at closing** - Or remote closing if needed
- **Verify payoff of existing mortgage** - Ensure lien release
- **Confirm commission disbursement** - Payment to listing and buyer agents

#### Post-Closing (Seller-Specific)
- **Forward any seller mail received** - Send to seller's new address
- **Remove lockbox and signage** - Clean up after closing
- **Update seller on deed recording** - Confirm transaction complete

### Rental - Landlord Representation (ONLY)

#### Listing Setup
- **Execute rental listing agreement** - Agreement with landlord
- **Determine rental price** - Market rental analysis
- **Establish fee structure** - Landlord pays agent or tenant pays
- **Collect property details** - Bedrooms, baths, amenities, utilities included

#### Property Preparation
- **Conduct pre-listing property inspection** - Note condition
- **Photograph rental property** - Listing photos
- **Verify property is ready to show** - Clean and presentable
- **Install lockbox for showings** - If approved by landlord

#### Required Legal Compliance (MA Rental Law)
- **Prepare compliant lease agreement** - Must include required disclosures
- **Include landlord contact information in lease** - Name, address, phone (required)
- **Include maintenance contact in lease** - Who handles repairs (required)
- **Disclose security deposit amount and rights in lease** - Required by law
- **Provide Statement of Condition form** - Within 10 days of lease or deposit (required)
- **Provide fire insurance disclosure** - Within 15 days of lease signing (required)
- **Lead paint disclosure (if pre-1978)** - Federal and MA requirement
- **Set up security deposit bank account** - Must be MA bank, interest-bearing (required)

#### Marketing & Tenant Screening
- **List property on rental platforms** - MLS, Zillow, Apartments.com, etc.
- **Coordinate rental showings** - Schedule and conduct tours
- **Collect rental applications** - Screen prospective tenants
- **Conduct tenant screening** - Credit, background, references, income verification
- **Verify tenant income** - Must be 3x monthly rent (standard)
- **Verify employment** - Contact employer
- **Contact references** - Previous landlords, personal references

#### Lease Execution
- **Select qualified tenant** - Make selection with landlord
- **Prepare lease documents** - Complete all required fields
- **Execute lease agreement** - Landlord and tenant signatures
- **Collect first month's rent** - At lease signing
- **Collect last month's rent (optional)** - If agreed
- **Collect security deposit** - Up to 1 month's rent maximum (MA law)
- **Provide receipt for all payments** - Required documentation
- **Deposit security deposit within 30 days** - Into MA interest-bearing account (required)
- **Provide tenant with bank account information** - Within 30 days (required)

#### Move-In Process
- **Conduct move-in inspection with tenant** - Complete Statement of Condition
- **Provide keys to tenant** - Access to property
- **Provide tenant with landlord/agent contact info** - Emergency contacts
- **Set up rent payment method** - Online, check, ACH, etc.

#### Ongoing Management (if applicable)
- **Coordinate maintenance requests** - If part of agreement
- **Conduct periodic property inspections** - With proper notice
- **Track lease renewal dates** - Plan for renewal or turnover

#### Initial Consultation
- **Execute tenant representation agreement** - Agreement with tenant
- **Disclose fee arrangement in writing** - Required at first meeting (MA law)
- **Understand tenant's needs** - Budget, location, size, amenities
- **Verify tenant's financial capacity** - Income requirements (typically 3x rent)
- **Obtain tenant's employment information** - For applications

#### Property Search
- **Search available rental listings** - MLS and rental platforms
- **Schedule property showings** - Coordinate tours
- **Provide market information to tenant** - Pricing, availability, neighborhood

#### Application & Screening
- **Prepare rental application for tenant** - Assist with application completion
- **Submit application to landlord/agent** - On behalf of tenant
- **Provide tenant references** - Previous landlords, employers

- **Verify lease includes required MA disclosures** - Lead paint, security deposit, contacts

- **Attend lease signing with tenant** - Support tenant at signing
- **Verify tenant receives all required disclosures** - Lead paint, insurance, bank info
- **Conduct move-in walkthrough** - Document property condition
- **Complete Statement of Condition with tenant** - Note all defects
- **Verify tenant receives keys** - Ensure property access
- **Provide tenant with important contacts** - Landlord, maintenance, utilities

## Property-Type Specific Tasks

### Single-Family Home - Septic System

**Applies to:** SFH with septic (not city sewer)

#### Title 5 Septic Inspection Requirements
- **Determine if Title 5 inspection required** - Required for sale (MA law)
- **Verify inspection within 2 years** - Inspection validity period
- **Schedule MA-certified Title 5 inspection** - Must be certified inspector
- **Review Title 5 inspection report** - Pass or fail determination
- **Coordinate Title 5 repairs (if system fails)** - Up to 2 years allowed for non-emergency
- **Schedule Title 5 re-inspection (if repairs made)** - Verify repairs successful
- **Obtain Certificate of Compliance from Board of Health** - Required for closing
- **Provide pumping records to buyer** - Historical maintenance documentation
- **Provide septic system diagram/location** - As-built or location sketch
- **Verify reserve area identified** - Future replacement area
- **Disclose septic system age and type** - Tank size, leach field type

**Legal Requirement:** Title 5 inspection must be completed within 2 years before sale, or within 6 months after if weather prevented inspection. Valid for 2 years (3 years if pumped annually).

**Timeline:** Allow 2-4 weeks for inspection scheduling; if failure, up to 2 years for repairs (but typically addressed before closing).

---

### Single-Family Home - Private Well

**Applies to:** SFH with private well (not city water)

#### Well Water Testing & Certification
- **Schedule comprehensive well water test** - Bacteria, nitrates, lead, arsenic, radon
- **Coordinate flow rate and recovery test** - Gallons per minute, recovery time
- **Review water test results** - Safe drinking water standards
- **Coordinate water treatment system transfer (if applicable)** - Softener, filtration, etc.
- **Provide well maintenance records** - Historical well servicing
- **Verify well location and depth** - Well log documentation
- **Verify 100-foot separation from septic** - MA minimum requirement
- **Disclose well age and type** - Drilled, dug, or artesian

**Legal Requirement:** While not legally required by MA, most lenders require comprehensive water testing.

**Timeline:** 7-10 days for test results; schedule during inspection period.

---

### Condominium

**Applies to:** All condominium units

#### HOA/Condo Association Requirements
- **Request condo association documents** - Master deed, bylaws, budget, meeting minutes, rules
- **Order 6(d) certificate** - M.G.L. c. 183A, § 6(d) certification
- **Review 6(d) certificate for unpaid fees** - "Clean" vs "dirty" certificate
- **Pay off any unpaid condo fees (if seller owes)** - Required for clean certificate
- **Complete condo questionnaire for buyer's lender** - HOA financial questionnaire
- **Review HOA financial statements** - Reserve fund, operating budget
- **Verify HOA is FHA/VA approved (if applicable)** - For certain loan types
- **Review HOA meeting minutes (12 months)** - Identify pending assessments or issues
- **Disclose any pending special assessments** - Future financial obligations
- **Verify parking space assignment** - Deeded or assigned
- **Verify storage unit assignment (if any)** - Deeded or assigned
- **Provide HOA contact information** - Property manager or board
- **Verify master insurance coverage** - HOA master policy
- **Arrange HO-6 insurance for buyer** - Unit owner policy (required)
- **Review condo association rules** - Pet policy, rental restrictions, etc.
- **Coordinate condo association transfer process** - Transfer fees, paperwork

**Legal Requirement:** 6(d) certificate required by law; must be issued within 10 days of written request (M.G.L. c. 183A, § 6(d)).

**Timeline:** Request 6(d) certificate immediately after P&S; allow 2-4 weeks for association to issue.

---

### Multifamily (Tenant-Occupied)

**Applies to:** Properties with existing tenants (2+ units or single-family rental)

#### Tenant Notifications & Lease Transfers
- **Gather all current lease agreements** - Copies of all tenant leases
- **Prepare rent roll** - List of all tenants, units, rent amounts, lease terms
- **Verify security deposit amounts** - Total deposits held
- **Prepare tenant estoppel certificates** - Tenant verification of lease terms
- **Send tenant estoppel requests** - To all tenants
- **Collect signed estoppel certificates** - Return from tenants
- **Notify tenants of property sale** - Provide reasonable notice per MA law
- **Coordinate showing access with tenants** - Respect tenant privacy rights
- **Transfer lease obligations to new owner** - Leases transfer automatically
- **Transfer security deposits to new owner** - Within 45 days (MA law)
- **Provide new owner with bank account information** - For security deposits
- **New owner sends security deposit notice to tenants** - Within 45 days (MA law)
- **Provide tenant contact information to buyer** - Names, phone, email
- **Disclose any tenant issues** - Late payments, violations, disputes
- **Review lease expiration dates** - Plan for renewals or turnovers
- **Calculate pro-rated rent at closing** - Adjust for closing date

**Legal Requirement:** Security deposits must be transferred to new owner; new owner must notify tenants within 45 days of new bank account information (MA law).

**Timeline:** Begin tenant coordination immediately after P&S; allow 2-3 weeks for estoppel collection.

---

### Commercial Property

**Applies to:** All commercial transactions

#### Environmental & Zoning
- **Order Phase I Environmental Site Assessment (ESA)** - Historical contamination review
- **Review Phase I ESA results** - Identify Recognized Environmental Conditions (RECs)
- **Order Phase II ESA (if needed)** - Soil and groundwater sampling
- **Verify zoning compliance** - Current use permitted
- **Verify certificate of occupancy** - Current CO for tenant uses
- **Review building permits** - All work properly permitted
- **ADA compliance review** - Accessibility requirements met

#### Commercial Lease Analysis (if tenant-occupied)
- **Collect all tenant lease agreements** - Current leases
- **Prepare detailed rent roll** - Tenant, unit, rent, term, options
- **Review lease terms and obligations** - Landlord vs tenant responsibilities
- **Verify CAM (Common Area Maintenance) charges** - Calculation and collection
- **Review tenant improvement allowances** - Any pending TI obligations
- **Verify percentage rent provisions (if applicable)** - Retail leases
- **Analyze lease expiration schedule** - Rollover risk
- **Review tenant estoppel certificates** - Tenant lease confirmations
- **Verify option rights** - Renewal options, expansion options, ROFO, ROFR
- **Review prohibited use clauses** - Tenant restrictions
- **Analyze operating expense escalations** - NNN, Modified Gross, Full Service

#### Commercial Financial Analysis
- **Collect 3 years operating statements** - Income and expenses
- **Analyze net operating income (NOI)** - Revenue minus operating expenses
- **Calculate capitalization rate** - NOI / Purchase Price
- **Review property tax assessments** - Verify current taxes
- **Analyze utility expenses** - Who pays what
- **Review insurance requirements** - Commercial property insurance
- **Verify property management fees** - If professionally managed

## Summary: Task Organization Strategy

### Recommended Database Structure

1. **Universal Task Library** - Tasks that apply to ALL transaction types
   - Store once with `applies_to_all = true`
   - Example: Agency Disclosure, Attorney Coordination, Commission Processing

2. **Transaction-Type Specific Task Library** - Tasks unique to transaction type
   - Flag with `transaction_type` field: 'buy_side', 'sell_side', 'rental_landlord', 'rental_tenant', 'commercial_buy', 'commercial_sell'
   - Example: "Sign Listing Agreement" = 'sell_side' only
   - Example: "Sign Buyer Agency Agreement" = 'buy_side' only
   - Example: "Conduct Tenant Screening" = 'rental_landlord' only
   - Example: "Review Lease with Tenant" = 'rental_tenant' only

3. **Property-Type Specific Task Library** - Tasks unique to property type
   - Flag with `property_type` field: 'sfh', 'condo', 'multifamily', 'land', 'commercial'
   - Flag with `property_attribute` field: 'has_septic', 'has_well', 'is_condo', 'tenant_occupied'
   - Example: "Order Title 5 Inspection" = property_type:'sfh' AND property_attribute:'has_septic'
   - Example: "Order 6(d) Certificate" = property_type:'condo'
   - Example: "Collect Tenant Estoppels" = property_attribute:'tenant_occupied'

4. **Conditional Application Logic**
   - Use `applies_if` field with boolean expressions
   - Example: `applies_if: "transaction_type == 'sell_side' AND property_type == 'condo'"`
   - Example: `applies_if: "property.has_septic == true"`
   - Example: `applies_if: "transaction_side == 'buyer' AND property.build_year < 1978"`

5. **Template Composition**
   - Templates should be composed dynamically based on:
     - Transaction Type (buy_side, sell_side, rental_landlord, rental_tenant, commercial)
     - Property Type (sfh, condo, multifamily, land, commercial)
     - Property Attributes (has_septic, has_well, tenant_occupied, etc.)
   - Example Template Logic:
     ```
     Template: "Condo Purchase (Buy Side)"
     = Universal Tasks (all)
     + Buy Side Tasks (transaction_type = 'buy_side')
     + Condo Tasks (property_type = 'condo')
     - Sell Side Tasks (excluded)
     - Rental Tasks (excluded)
     ```
