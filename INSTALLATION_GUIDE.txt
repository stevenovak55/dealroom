OPTION 1: Via WordPress Admin (Recommended)

1. Log in to your WordPress admin panel
   → https://your-site.com/wp-admin

2. Navigate to: Plugins → Add New → Upload Plugin

1. Upload the ZIP to your server:

3. Install the plugin:
   wp plugin install /tmp/ma-deal-room-v2.0.0.zip --activate

4. Run migrations:
   wp ma-deal migrate


⚙️ POST-INSTALLATION CONFIGURATION
--------------------------------------------------------------------------------

CRITICAL: Set up environment variables!

1. Create .env file in plugin directory:
   /wp-content/plugins/ma-deal-room/.env

2. Copy from .env.example (on GitHub) or use this template:

   # Database (usually auto-configured by WordPress)
   DB_NAME=your_database_name
   DB_USER=your_database_user
   DB_PASSWORD=your_database_password

   # JWT Secrets (REQUIRED - Generate with: openssl rand -base64 64)
   JWT_SECRET_KEY=YOUR_GENERATED_SECRET_HERE
   JWT_REFRESH_SECRET_KEY=YOUR_GENERATED_SECRET_HERE

   # Email Service (Optional - uses wp_mail() if not set)
   SENDGRID_API_KEY=your_sendgrid_key

   # SMS Service (Optional)
   TWILIO_ACCOUNT_SID=your_twilio_sid
   TWILIO_AUTH_TOKEN=your_twilio_token
   TWILIO_FROM_NUMBER=+1234567890

   # CORS (Set your frontend domain)
   CORS_ALLOWED_ORIGINS=https://your-site.com
   FRONTEND_URL=https://your-site.com

   # Environment
   ENVIRONMENT=production
   WP_ENV=production

3. Generate JWT secrets:
   On your computer/server:
   openssl rand -base64 64
   (Run twice, once for each secret)

4. Set proper file permissions:
   chmod 600 .env

For reminders and background tasks to work, add these cron jobs:

Add these lines:

# Process background job queue every 15 minutes

# Clean up old sessions daily

Replace /path/to/wordpress with your actual WordPress installation path.

🔧 TROUBLESHOOTING
--------------------------------------------------------------------------------

Problem: Plugin won't activate
Solution:
- Check PHP version: must be 8.0 or higher
- Verify Composer dependencies are included in ZIP
- Check error logs: /wp-content/debug.log

Problem: "Database error" on activation
Solution:
- Ensure database user has CREATE TABLE permissions
- Check MySQL version (8.0+ required)
- Verify database connection in wp-config.php

Problem: React admin doesn't load
Solution:
- Verify dist/assets/index.js exists in plugin folder
- Clear browser cache
- Check for JavaScript errors in browser console

Problem: JWT authentication fails
Solution:
- Verify .env file exists and is readable
- Check JWT secrets are set (not defaults)
- Ensure WordPress .htaccess allows Authorization header

Problem: Email/SMS not sending
Solution:
- Check SENDGRID_API_KEY or TWILIO credentials
- Verify environment variables are loaded
- Check WordPress wp_mail() is working
- Review email logs (if configured)
